IJUL MUTTAQIN — PORTFOLIO WEBSITE

A self-contained static portfolio website based on the supplied portfolio PDF.
Style: Swiss / International Typographic Style + Y2K / Acid Graphics.
Brand palette: black, white, red.

FILES
- index.html  : website structure/content
- style.css   : visual system and responsive layout
- script.js   : navigation state + back-to-top button
- assets/     : extracted portfolio images, kept in their original aspect ratios

RUN LOCALLY
1. Open index.html in a modern browser, or
2. Run a local server from this folder, e.g.:
   python3 -m http.server 8000
   Then visit http://localhost:8000

DEPLOY
Upload the entire folder to a static hosting provider such as GitHub Pages, Netlify,
Vercel, or any normal web hosting service. Keep the assets folder beside index.html.
